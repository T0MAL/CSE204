1. List.java is the ADT of the List
2. Linked list(LL.java) implements the List ADT and is created by extending the Node.java file
3. Node.java represents every node of the Linked List and the Linked List is implemented as Doubly Linked List
3. Arr.java is the array based implementation of the List ADT
4. Main.java is the driver program for surfing different functions of the List
5. TNL.java is the implementation of transit network line (TNL) from Point A to Point B using the array and Linked List based implementation of the List
