1. Stack.java is the ADT of the Stack
2. LL.java implements the Stack ADT and is created by extending the Node.java file
3. Node.java represents every node of the Linked List and the Linked List is implemented as Doubly Linked List
4. Arr.java is the array based implementation of the Stack ADT
5. Main.java is the driver program for surfing different functions of the Stack
6. Dishwasher_Arr.java is the implementation of the Dishwasher problem using the array based implementation of the Stack
7. Dishwasher_LL.java is the implementation of the Dishwasher problem using the Linked List based implementation of the Stack
8. Dishwasher1A2S.java is the implementation of the Dishwasher problem using 1 array 2 stack
